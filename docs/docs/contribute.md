# Let us know!

We are student developers learning to design a reliable system. If you see a problem, security issue, architectural flaw, or anything else with our design, please [notify](https://github.com/acd-research-repo/research-repository/issues) us so we can improve. This is open source by choice so you can help us and also check the reliability of the system we are creating.
